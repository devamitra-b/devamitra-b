## 👨‍💻 About Me

🎓 I am an Electronics & Communication Engineering student at Bannari Amman Institute of Technology.

I specialize in turning electronics concepts into practical systems by integrating hardware, firmware, communication protocols, and software.

### 🎯 Core Interests

- Embedded Systems — microcontroller-based design and firmware development
- Internet of Things (IoT) — connected devices, data collection, and cloud integration
- Embedded Communication & Networking — wireless protocols, low-power connectivity

**Mission:** Build reliable, scalable systems where electronics and software work harmoniously.
